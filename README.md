# 🚀 Laravel Reverb & WebSockets

Aplicación monolítica desarrollada para explorar e implementar la comunicación en tiempo real utilizando **Laravel Reverb**, integrada dentro del moderno ecosistema de **Laravel, Inertia.js, Vue 3, Pinia y TypeScript**.

## 🌟 Características Principales

- **Chat en Tiempo Real 1v1:** Mensajería instantánea y fluida entre usuarios utilizando WebSockets.
- **Sistema de Presencia Global:** Detección automática y en tiempo real del estado online/offline de los usuarios en toda la aplicación.
- **Gestión de Estado Centralizada:** Uso de Pinia para mantener sincronizado el estado de conexión sin importar la navegación de Inertia.
- **Tipado Estricto:** Desarrollado con TypeScript para garantizar robustez y autocompletado en todo el frontend.
